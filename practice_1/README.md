# Практика №1: классификатор k ближайших соседей

Задача: по ответам на анкету (44 респондента) предсказать, каким телефоном пользуется человек — Айфон или Андроид.

## Результаты

- Лучшее k = 11 (евклидова метрика, веса `distance`, MinMaxScaler); хороший диапазон k — 9–13
- Нормировка признаков обязательна: без неё качество заметно падае
- Точность ~0.64 — на уровне baseline «всегда Андроид», но по balanced accuracy и F1-macro модель лучше
- Главные причины невысокого качества: мало данных, слабая связь вопросов анкеты с целью, дисбаланс классов
